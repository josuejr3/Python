
#### <span style="color:rgb(4, 255, 0)">Trabalhando com planilhas e usando módulo openpyxl</span>

A biblioteca openpyxl é uma biblioteca dedicada para manipular arquivos de planilha, principalmente os excel. xlsx, xlsm, xltx e xltm. 

Com essa biblioteca conseguimos ler e escrever dados em células específicas, formatar células, inserir gráficos, criar fórmulas, adicionar imagens e outros elementos gráficos às suas planilhas. 

Ela é útil para automatizar tarefas envolvendo planilhas do Excel, como a criação de relatórios e análise de dados e/ou facilitando a manipulação de grandes quantidades de informações.
