
#### <span style="color:rgb(4, 255, 0)">Web Scraping</span>

Web Scraping é o "ato" de "raspar a web" ou seja, buscar informações de forma automatizada com uma determinada linguagem de programação para um uso posterior.

Para fazer web scraping nós podemos usar tanto o módulo requests, como também o bs4 BeautifulSoup. 

O primeiro é responsável por obter os dados, ou seja, ele é quem carrega os dados da internet para o projeto. Já o bs4.BeautifulSoup é responsável por interpretar os dados HTML da página e transformar os dados em objetos Python, facilitando a vida do desenvolvedor.
