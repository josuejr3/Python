##### Variáveis livres e nonlocal

Exemplo de variável livre

```Python
def fora(x):
	a = x
	def dentro():
		return x
	return dentro
```

Para entender o conceito de variável livre, temos que relembrar de Closure, que é quando temos uma função dentro de outra função que guarda um valor e retorna a função sem chamar ela. 

No exemplo acima, "a" é considerada uma variável livre, pois ela não está definida dentro do escopo da função "dentro", ela se encontra somente no escopo da função mais externa, "fora".

```Python
dentro = fora(10)
print(dentro())  # dentro é um função retornada, que não recebe parâmetros
				 # ela retorna o valor de x
```

Caso eu ainda esteja na dúvida sobre o escopo de variáveis, posso usar as funções *locals* e *globals* que retornam as variáveis que são locais e globais, respectivamente.

A variável "a" é livre, pois ela não está definida dentro.

##### Funções decoradoras no geral.

Funções decoradoras, decoradores ou decorators, "são coisas que decoram outras coisas". O significado é de que estou recebendo alguma coisa, decorando o que foi recebido e retornando um outro valor, o mesmo valor ou até nenhum valor. ==Decorar é adicionar, remover, restringir ou alterar uma determinada função===. 

**Obs: para isso deve se usar closure, que foi um conceito que vimos anteriormente**

```Python
def inverte_string(string):
	return string[::-1]

invertida = inverte_string("Luiz")
```

-  Funções devem ter uma única responsabilidade;
-  No caso acima, como a função recebe uma string, é necessário verificar se o parâmetro não foi de outro tipo, para isso é necessário criar uma função que faz isso e não reaproveitar a própria que inverte.

```Python
def is_string(string):
	if isinstance(string, str):
		return True
	return False
```

Segue abaixo um exemplo do uso de decoradores.

```Python
def inverte_string(string):  
    return string[::-1]  
  
# função decorada - closure  
def make_function(func):  
    def interna(*args, **kwargs):  
		print("vou te decorar")
        for arg in args:  
            is_string(arg)  
  
        result = func(*args, **kwargs)  
        #  
        print("vc foi decorada")
        return result  
    return interna  
  
def is_string(string):  
    if not isinstance(string, str):  
        raise TypeError("O parâmetro não é uma string")  
  
invertida_string_checando_parametro = make_function(inverte_string)  
invertida = invertida_string_checando_parametro(123)  
print(invertida)
```

-  A função decoradora é a *make_function* a função dela é criar uma função interna, para que eu possua um *closure* e a função interna não será executada, ela vai ser retornada sem execução.

##### Decoradores em Python - @syntax_sugar

Decoradores no Python são "syntax sugar", ou, "açúcar sintático". O que quer dizer que a linguagem facilita a forma como escrevemos.

A forma que usamos é o seguinte:

```Python
# Existe uma função decoradora definida

@make_function
def inverte_string(string):
	print(f"{inverte_string.__name__}")
	return string[::-1]
```

Nesse caso, queremos usar a função "make_function" na função "inverte_string". O print acima vai ter como saída o nome "interna", o Python trocará a função "inverte_string" pela "interna".
##### Decoradores com parâmetros

```Python
def decoradora(func):  
    print("Decoradora 1")  
    def aninhada(*args, **kwargs):  
        print("Aninhanda")  
        res = func(*args, **kwargs)  
        return res  
    return aninhada  
  
@decoradora  
def soma(a, b):  
    return a +b  
  
dez_mais_cinco = soma(10, 5)  
print(dez_mais_cinco)
```

No exemplo acima, tem-se o seguinte procedimento

1.  A função soma é chamada com parâmetros 10 e 5;
2.  A função soma está relacionada com o decorador "decoradora";
3.  Sendo assim, a função "decoradora" é chamada passando como parâmetro a função "soma" junto com os parâmetros 10 e 5;
4.  Os valores 10 e 5 são salvos em args e kwargs de uma nova função "aninhada";
5.   A função aninhada retorna o valor de retorno da função passada como parâmetro, ou seja, vai retornar o valor retornado pela função soma; 
6.  A função decoradora vai retorna a função aninhada;

===Obs: as funções internas podem ser chamadas de inner functions, inner, nested, ou nested function.

```Python
multiplica = decoradora(lambda x, y: x * y)
```

As funções decoradoras são "fábrica de funções", ou seja, são responsáveis por criarem outras funções. Porém, eu posso ter uma "fábrica de decoradores". 

```Python
def fabrica_de_funcoes(func):  
    print("Decoradora 1")  
    def aninhada(*args, **kwargs):  
        print("Aninhanda")  
        res = func(*args, **kwargs)  
        return res  
    return aninhada  
  
# exemplo de uma fabrica de decoradores  
def fabrica_de_decoradores(a, b, c):  
    return fabrica_de_funcoes  
  
@fabrica_de_funcoes  
def soma(a, b):  
    return a +b  
  
dez_mais_cinco = soma(10, 5)  
print(dez_mais_cinco)
```

Para executar a 'fábrica de decoradores', eu devo usar "()".

```Python
@fabrica_de_decoradores(a, b, c)
```

##### Ordem de aplicação de decoradores

A execução de múltiplos decoradores em uma função é de baixo para cima, segue o exemplo abaixo. 

```Python
@parametros_decorador(nome="segundo")  
@parametros_decorador(nome="primeiro")  
def soma(a, b):  
    return a + b
```

Nesse caso, primeiro o decorado "primeiro" é executado com a função soma, para só então o decorador "segundo" ser executado. Segue abaixo o código completo.

```Python
def parametros_decorador(nome):  
    def decorador(func):  
        print("Decorador:", nome)  
  
        def sua_nova_funcao(*args, **kwargs):  
            res = func(*args, **kwargs)  
            final = f"{res} {nome}"  
            return final  
  
        return sua_nova_funcao  
    return decorador  
  
@parametros_decorador(nome="segundo")  
@parametros_decorador(nome="primeiro")  
def soma(a, b):  
    return a + b  
  
dez_mais_cinco = soma(10, 5)  
print(dez_mais_cinco)
```

##### Juntando duas listas

```Python
def zippr(lista1, lista2):  
    # descobrindo menor indice entre listas  
    intervalo = min(len(lista1), len(lista2))  
  
    # usando list comprehension ele já adiciona automaticamente  
    return [  
        (lista1[i], lista2[i]) for i in range(intervalo)  
    ]  
  
  
l1 = ["Salvador", "Ubatuba", "Belo Horizonte"]  
l2 = ["BA", "SP", "MG", "RJ"]  
print(zippr(l1, l2))
```

O código acima representa uma forma de combinar duas listas, levando em consideração o tamanho da menor. Entretanto, já existe uma função em Python que combina dos iteráveis chamada *"zip"*. Porém, ela retorna um iterator, para ver o iterator é necessário consumir ele através de uma lista ou então fazer um *for*.

```Python
l1 = ["Salvador", "Ubatuba", "Belo Horizonte"]  
l2 = ["BA", "SP", "MG", "RJ"]  
print(list(zip(l1, l2)))
```

Nesse caso, utilizamos como padrão o tamanho da lista menor, porém, poderíamos ter optado pela lista maior. Para isso, ao invés de usar o método zip, seria necessário usar o método *"zip_longest"*. Esse método encontra-se na *lib itertools* e como ficariam "faltando" elementos para completar, poderiamos usar o parâmetros *fillvalue*.

```Python
from itertools import zip_longest  
print(list(zip_longest(l1, l2, fillvalue="Sem Cidade")))
```
