
-  Docstrings servem para comentar, porém, não são comentários.
-  A função print é usada para exibir algo na tela, ela recebe um argumento.
-  A função print coloca um separador, que separa os argumentos, por padrão é o " ".

##### Tipos

*  Strings: são textos e são definidos com dentro de aspas simples ou duplas ("", '');
*  Caracteres de escape: \", \n, \' ... (por definição é uma barra invertida e o símbolo que eu quero que apareça)
*  Outra alternativa é usar o r
*  Uma outra opção é alterar as aspas, se eu usei "" para definir strings, eu uso '' para ser exibido;
---
-  Int: são os números inteiros.
-  Float: são os números de ponto flutuante, ou seja, números quebrados
-  função type(objeto) -> retorna o tipo do objeto
-  **Tudo em Python é um objeto**
-  bool: retorna True ou False, esse tipo de operador é usado para "questionar" alguma coisa.

##### Typecasting/Conversão/Coerção de Tipos

Só podem ser feitos por tipos iguais, ou que se combinem, verificar exemplo abaixo. 

```Python
print(1+1)
print("a"+"b")
# print(1+"1") # Erro, tipos diferentes
```

-  Linguagens de tipagem fraca convertem em um outro tipo, um caso como esses. (Ex: Javascript)
-  Linguagens fortes com o Python, lançam um erro por não saber lidar com esse tipo de situação.

> Os tipos que vimos até agora, int, string, float e bool são tipos primitivos e imutáveis.

-  Podemos converter usando funções que convertem. 

```Python
print(int("1"), type("1"))
```

-  ===Obs: int(), str() e type() são classes==
-  ===Obs2: strings vazias são consideradas False e com algum caractere são True
