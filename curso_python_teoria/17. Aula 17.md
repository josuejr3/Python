
##### Combinations, Permutations e Product - Itertools

Alguns tópicos importantes que vimos na matemática podem não ser tão simples de se fazerem na programação. O módulo itertools tem algumas funções que nos ajudam a manipular dados a partir de tópicos matemáticos, como por exemplo o citados abaixo.

-  Combinações - é um iterável em que a ordem dos elementos não importa;
-  Permutações - é um iterável em que a ordem dos elementos é importante;
-  Produto - também é um iterável, os elementos podem se repetir e a ordem importa;

```Python
pessoas = ["Joao", "Joana", "Luiz", "Leticia"]
camisetas = ["preta", "branca"]
```

===Obs: a maioria dos retornos do módulo itertools retornam iterators===

Segue abaixo um exemplo usando a função *combinations*.

```Python
from itertools import combinations, permutations

def print_iter(iterator):  
    print(*list(iterator), sep="\n")  
    
pessoas = ["Joao", "Joana", "Luiz", "Leticia"]  
camisetas = ["preta", "branca"]  
  
print_iter(combinations(pessoas, 2)) # o argumnento 2 se refere a quantidade de elementos
```

Como nas combinações a ordem não importa, então elementos não são repetidos, ou seja, se já exibimos "Joao-Joana", não há necessidade de exibirmos "Joana-Joao".

```Python
# saída
# ('Joao', 'Joana')
# ('Joao', 'Luiz')
# ('Joao', 'Leticia')
# ('Joana', 'Luiz')
# ('Joana', 'Leticia')
# ('Luiz', 'Leticia')
```

Da mesmo modo que fizemos com as combinações, podemos fazer também com as permutações, entretanto, agora a ordem que os elementos estão disponibilizados importa,. Sendo assim, a saída deve apresentar tanto o "Joao-Joana", como também, o "Joana-Joao".

```Python
print_iter(permutations(pessoas, 2))

# saída
# ('Joao', 'Joana')
# ('Joao', 'Luiz')
# ('Joao', 'Leticia')
# ('Joana', 'Joao')
# ('Joana', 'Luiz')
# ('Joana', 'Leticia')
# ('Luiz', 'Joao')
# ('Luiz', 'Joana')
# ('Luiz', 'Leticia')
# ('Leticia', 'Joao')
# ('Leticia', 'Joana')
# ('Leticia', 'Luiz')
```

Por fim temos o produto, que nada mais é do que o produto cartesiano entre dois iteráveis. Sendo assim, ele faz a "combinação" entre cada elemento do primeiro iterável, com cada elemento do segundo iterável, com o uso de repetições.

```Python
camisetas = [  
    ["preta", "branca"],  
    ["p", "m", "g"],  
]

# * desempacota a lista de listas
print_iter(product(*camisetas))

# saída
# ('preta', 'p')
# ('preta', 'm')
# ('preta', 'g')
# ('branca', 'p')
# ('branca', 'm')
# ('branca', 'g')
```

##### Groupby - itertools

O groupby é uma função também do módulo itertools que serve para agrupar os dados do iterável. 

===Obs: para usar essa função é importante que o iterável esteja ordenado===

```Python
from itertools import groupby  
  
alunos = [  
    {"nome": "Luiz", "nota": "A"},  
    {"nome": "Leticia", "nota": "B"},  
    {"nome": "Fabricio", "nota": "A"},  
    {"nome": "Rosemary", "nota": "C"},  
    {"nome": "Joana", "nota": "D"},  
    {"nome": "Joao", "nota": "A"},  
    {"nome": "Eduardo", "nota": "B"},  
    {"nome": "Andre", "nota": "A"},  
    {"nome": "Anderson", "nota": "C"},  
]  
  
  
# passa o aluno e retorna pela chave "nota"  
alunos_agrupados = sorted(alunos, key= lambda aluno: aluno["nota"])  
  
grupos = groupby(alunos_agrupados, key=lambda aluno: aluno["nota"])  
  
for chave, grupo in grupos:  
    print(chave)  
    print(list(grupo))
```

Na groupby é necessário informar por qual chave se deseja organizar, do contrário ele usará os dicionários. 

Como há repetição de código nas duas funções lambda, podemos ajustar da seguinte maneira.

```Python
def ordena(aluno):  
    return aluno["nota"]  
  
alunos_agrupados = sorted(alunos, key=ordena)  
  
grupos = groupby(alunos_agrupados, key=ordena)  
  
for chave, grupo in grupos:  
    print(chave)  
    for aluno in grupo:  
        print(aluno)
```

##### Map, Partial, GeneratorType e esgotamento de Iterators.

Quando estudamos list-comprehension vimos que podemos fazer um mapeamento ou filtro dentro da "estrutura". 

Segue o exemplo usando o mapeamento para aumentar preços de produtos em 10%

```Python
def print_iter(iterator):  
    print(*list(iterator), sep="\n")  
    print()  
  
produtos = [  
    {"nome": "Produto 5", "preco": 10.00},  
    {"nome": "Produto 1", "preco": 22.32},  
    {"nome": "Produto 3", "preco": 10.11},  
    {"nome": "Produto 2", "preco": 105.87},  
    {"nome": "Produto 4", "preco": 69.90},  
]  
  
  
# relembrando mapeamento  
  
def aumentar_porcentagem(valor, porcentagem):  
    return round(valor * porcentagem, 2)  
  
novos_produtos = [{**p,  
                   "preco": aumentar_porcentagem(p["preco"], 1.1)}  
                  for p in produtos  
                  ]  
  
print_iter(produtos)  
print_iter(novos_produtos)
```

Nesse caso, a lista comprehension ficou muito grande, para resolver isso podemos criar uma função que faz o arredondamento de valores. Para isso, vamos usar uma ferramenta chamada *partial* que é uma função que recebe uma outra função. Essa função está localizada em um módulo chamado *"functools"*, ou seja, ferramentas de funções. 

```Python
from functools import partial  
  
aumentar_dez_porcento = partial(aumentar_porcentagem, porcentagem=1.1)
```


-  Map

O mapeamento é basicamente o que fizemos antes, para modificar o preço dos produtos. Porém de uma forma diferente.

```Python
def aumenta_preco(produto):  
    return {**produto, "preco": aumentar_dez_porcento(produto["preco"])}  

novos_produtos = map(  
    aumenta_preco,  
    produtos  
)
```

Na função map basicamente eu defino a variável e passo como parâmetros o que eu desejo aplicar nos novos produtos, que nesse caso é o **aumenta_preco**, sem executar, e passo também os meus produtos. 

Quando printamos, o que vamos obter é um objeto do tipo "map". Com isso, verificamos se ele possui os métodos __ iter __ e __ next ___ para fazer com que o map seja consumido pelo for. 

```Python
print(hasattr(novos_produtos, "__iter__"))
print(hasattr(novos_produtos, "__next__"))
```

Como ele possui ambos os atributos/métodos significa que é um iterator e podemos consumi-lo. 

==Ok, verificamos que ele é um iterator, porém, ele pode ser um generator também, o que significa que é importante nós conferirmos, para isso podemos usar o módulo types==

```Python
from types import GeneratorType

print(isinstance(novos_produtos, GeneratorType))
```

O iterator ele é esgotado, para não esgotar o iterator eu devo converter direto para uma lista. 

	Outro exemplo usando map

```Python
print(
	  map(
		lambda x: x  + 7
		[1, 2, 3, 4]
	  )
)
```

-  Filter

Assim como no map, a função filter recebe dois parâmetros, sendo elas uma função que será aplicada a cada elemento (sem executar), e o segundo, nesse caso, a lista de produtos. 

```Python
novos_produtos = filter(
	lamdba p: p["preco"] > 10
	produtos
)
```

```Python
novos_produtos = filter(  
    lambda p: p["preco"] > 100,

)  
  
print(novos_produtos)

```

 -  Reduce

A função reduce, como o próprio nome já diz é usada para reduzir um iterável em um único valor.  Por exemplo, numa situação em que temos uma lista de dicionários e cada dicionário possui um produto com nome e preço. Posso usar o reduce para saber o total do valor dos produtos.

===Obs: o Python "bruto" não possui a função nativamente, devemos importar do functools.===

```Python
from functools import reduce

produtos = [  
    {"nome": "Produto 5", "preco": 10.00},  
    {"nome": "Produto 1", "preco": 22.32},  
    {"nome": "Produto 3", "preco": 10.11},  
    {"nome": "Produto 2", "preco": 105.87},  
    {"nome": "Produto 4", "preco": 69.90},  
]
```

A sintaxe do reduce está exemplificada abaixo.

```Python
total = reduce(  
    #funcao_do_reduce,  
    #produtos, (o iterável)
    #valor_inicial_do_acumulador (normalmente 0)  
)
```

===Obs: posso até usar sem valor inicial, porém ocorrerá um transtorno.===

-  A função de dentro do reduce vai receber dois parâmetros:
	 -  Um acumulador;
	 -  Um produto dentro dos meus produtos;

```Python
def funcao_do_reduce(acumulador, produto):
	print(acumulador)
	return 1

total = reduce(
	funcao_do_reduce,
	produtos,
	0
)
```

Na primeira execução da minha função reduce o total vai ser o valor inicial, ou seja, 0. Se não for passado nenhum valor inicial, será o primeiro elemento do iterável. A variável "total" é o nosso acumulador.

-  Se eu passo o valor inicial, o primeiro valor vai estar em "produto".
-  Se eu não passo o valor inicial, o primeiro produto vai ser o primeiro elemento do iterável, ele estará na variável "acumulador" e o segundo vai ser o da variável 'produto', ou seja, a contagem vai contabilizar o primeiro e o segundo de uma única vez. 

===Obs: Recomendado definir um inicio, pois se no caso eu estiver acumulando um determinado valor de uma estrutura de dados, como um dicionário e o valor inicial do acumulador é um dicionário e o do produto é um inteiro, ocorrerá um erro devido aos tipos===

```Python
def funcao_do_reduce(acumulador, produto):  
    print("acumulador: ", acumulador)  
    print("produto: ", produto)  
    print()  
    return acumulador + produto["preco"]  
  
total = reduce(  
    funcao_do_reduce,  
    produtos,  
    0  
)  
  
print("Total: ", total)
```

Usando funções lambda, temos:

```Python
total = reduce(
	lambda ac, p: ac + p["preco"],
	produtos,
	0
)
```
