##### Interpolação de Strings

A interpolação de strings é basicamente formas que temos de formatar alguns tipos de dados com strings.

Tipos:

-  s:        - string normal
-  d e i   - inteiros
-  f:        -  float
-  x e X  - hexadecimal (012345678ABCDEF)

A sintaxe é a seguinte

```Python
frase + % (opção de dado) % (nome da variavel)
```

```Python
nome = "Josue"  
preco = 1000.986453  
variavel = "%s, o preco total foi de: R$%.2f" % (nome, preco)  
print(variavel)
```

Podemos definir o número de casas decimais, basta acrescentar o *.2f* no ponto flutuante. 

##### f-strings

- Tudo que funciona com f-strings funciona com o format visto anteriormente. 
-  Com f-strings podemos fazer padding

```
padding é uma forma de espaçamento a esquerda ou a direita.
```

```Python
# SINTAXE
print(f"{variavel: >10}")   # Para a esquerda
print(f"{variavel: <10}")   # Para a direita
print(f"{variavel: ^10}")   # Centro
```

Além disso, posso usar outras opções, tais como: mostrar sinal de um número, definir separador de unidade, dezena, centena... e também a quantidade de casas decimais como vimos anteriormente. 

```Python
print(f"{-10000.3849384934932432:+,.1f}")
```

-  Conversion flags: !r !s e !a
São usados para chamar os métodos 

```
__repr__
__str__
__ascii__
```
##### Fatiamento de strings

O fatiamento de strings serve para dividir ou poder escolher o que se quer retirar ou o que se é necessário da string base. A função len retorna o tamanho da string, ou seja, a quantidade de caracteres presentes. Outros iteráveis também podem usar a função para retornar o tamanho, como listas, tuplas e filas. 

```Python
v_hw = "Ola mundo"
print(variavel[4:]) -> do indice 4 até o final
print(variavel[:4]) -> do inicial até o indice 4

# Podemos usar indices negativos
```

##### Try - Except

-  Try - tente
-  Except  - exceto

A diferença de um try-except para um if-else é que o segundo ele chega condições e altera o fluxo. O if não evita erros (exceções). 

A sintaxe do try-except é semelhante a do if-else

```Python
try:
	...
except:
	...
```
