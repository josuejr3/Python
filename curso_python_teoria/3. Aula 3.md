
-  A função de input( ) serve para coletar algum dado do usuário.

```Python
input('Qual o seu nome? ')
```

-  O retorno é sempre do tipo string
-  Posso fazer a conversão de tipos já na coleta de entrada, **PORÉM** não é recomendado
-  O ideal é fazer a coerção de tipos em outra variável.

```Python
# Errado / não recomendado
num1 = int(input("Digite um número: "))

# Correto
num1 = input("Digite um número: ")
num1_int = int(num1)
```

##### Operações Condicionais

Divide o código em blocos, if, elif e else: se, se não se, se não.

```Python
entrada = input('Você quer "entrar" ou "sair" ?')  
  
if entrada == "entrar":  
    print("Voce entrou no sistema")  
elif entrada == "sair":  
    print("Voce saiu do sistema")  
else: print("erro")
```

##### Operadores lógicos

-  AND: é o operador lógico E ele é considerado verdadeiro e todas as condições forem verdadeiras.
```
c1 = True AND c2 = True AND c3 = True  == True
c1 = False AND c2 = True AND c3 = True == False
```

Podem ser consideradas expressões falsy: 0, 0.0, '' e False.

> **Tipo NONE** é um tipo de não valor, ou não existe, representa um *NADA*

-  OR: se qualquer condição for verdadeira toda a expressão é avaliada como verdadeira. Também são consideradas como falsy os valores vistos anteriormente. Além de também existir o **None** para indicar um não-valor.

-  NOT: usado para inverter expressões

```
not False = True
not True = False
```

-  IN e NOT IN: operadores que envolvem iteráveis, ou seja, podemos percorrer.

```
     INDICES
 0  1  2  3  4  5 
 O  T  A  V  I  O
-6 -5 -4 -3 -2 -1
     INDICES
```

```Python
nome = "OTAVIO"  
print(nome[2])  
print(nome[-4])  
  
# exemplos de uso de verificao se esta EM  
print('A' in nome)  
print('Z' in nome)  
print("VIO" in nome)
```
