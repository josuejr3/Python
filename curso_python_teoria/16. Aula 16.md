##### O count é um iterador sem fim

O count só usa o start e o step, ele não possui o stop. O count é um método que se encontra na *lib itertools*. 

```Python
from itertools import count  
  
c1 = count(start=8, step=8)  
# o range é finito  
r1 = range(10)
```

O count nessa situação é um iterator e toda vez que eu chamo o **next** ele entrega o valor e soma mais. 

```Python
print(c1.__next__())  # 0
print(c1.__next__())  # 1
```

==Obs: lembrando que a função count( ) é diferente do método .count( ). O método .count( ) é usado para contar quantas vezes um elemento aparece em um iterável. Já a função da lib itertools é um iterador infinito que gera números a partir de um valor inicial aumentando e incrementando em 1 a cada chamada.

```Python
from itertools import count  
  
c1 = count()  
# o range é finito  
r1 = range(10)  
  
print(c1.__next__())  
print(c1.__next__())  
  
# verificando se eh um iterator  
print("c1", hasattr(c1, "__iter__"))  # garante que tem um iter  
print("c1", hasattr(c1, "__next__"))  # garante que tem um next  
print("r1", hasattr(r1, "__iter__"))  # garante que tem um iter - é um iterável  
print("r1", hasattr(r1, "__next__"))  # garante que tem um next - não é um iterator  
  
# loop infinito
  
for i in c1:  
    if i > 100:  
        break    print(i)
```

A diferença entre o count e o range é que o count é infinito e que o range não. Além disso, o range não é um iterator.
