##### Constantes e variáveis

-  Constantes são dados que não serão alterados durante o código e por esse motivo nos escrevemos em caixa alta. 

-  Variáveis são usadas para guardar dados.

```Python
velocidade_atual = 100
VELOCIDADE_MAX = 250
```

===Uma observação importante em relação aos if's e else's é que conforme aumentamos a quantidade de condições fica mais "difícil" o código, ou seja, aumentamos a complexidade.===

-  Em Python, podemos usar a "barra invertida ( \ )" para fazer uma quebra de linha invertida.

Em Python, diferente de C e C++ existe uma função específica para saber qual o identificador da memória de uma variável. A função usada é a id()

##### Flags is, is not e None

As flags, do português, bandeira, servem como uma forma de sinalizar se um código "passou" por um determinado algoritmo. 

```Python
condicao = False  
  
if condicao:  
    # passou_if = True  
    print("Faça algo")  
else:  
    print("Nao faça algo")  
  
# print(passou_if) -> erro pois a variavel so esta definida no if, se ela entra no else passou_if não existe
```

Uma forma de melhorar esse código seria

-  Definir a variável fora do bloco condicional;
-  Atribuir o valor "None", que significa "Nenhum".

```Python
condicao = False
passou_no_if = None

if condicao:
	passou_no_if = True
	print("Faça algo")
else:
	print("Não faça algo")
	
print(passou_no_if, passou_no_if is None)
```

Quando usamos None, normalmente não usamos operadores de == ou !=. O correto é fazer uso do "is" e do "not is"
##### Tipos built-in

O python oferece tipos ==imutáveis== que já conhecemos anteriormente, são eles: ==str, int, float e o bool.== 

-  Provando que strings são imutáveis
```Python
string = "Luiz Otavio"
string[3] = "ABC"
print(string[3])

# erro, strings imutáveis
```

Os métodos de string não alteram a string, eles retornam a string alterada.
