##### Listas

Lista em Python é um tipo de dado "maior", ou seja, é uma estrutura de dados.

Elas podem:
-  Ser alteradas, mudar o tamanho, conter diversos tipos;
-  Podemos usar índices e fatiamentos (estudados antes);
-  Possuem métodos específicos.

		- append
		- insert
		- pop
		- del
		- clear
		- extend

Acessamos os elementos de uma lista do mesmo jeito que acessamos os caracteres de uma string, índice por índice.

-  Podemos instanciar listas em Python de duas formas diferentes

```Python
lista = list()
# ou
lista = []
```

===Obs: uma lista vazia é considerada *Falsy*

-  Lista armazenando tipos distintos.

```Python
other_list = [123, True, "Luiz Otavio", 1.2, []]
```

O acesso por index é semelhante as strings, porém, ao invés de acessarmos a letra, estamos acessando o item presente na lista. Dessa forma:

```Python
print(other_list[0])      # -> 123
print(other_list[2][5])   # -> "O", 5º letra na string que está na pos 2
```

O acesso por índice negativo também é válido.

```Python
# Alterando a string 
other_list[2]= other_list[2].upper()  
print(other_list) # -> [123, True, 'LUIZ OTAVIO', 1.2, []]
```

-  O método del faz com que deletemos um dos elementos presentes na lista

```Python
del lista[2]
```

===Obs 1: podemos deletar o último item da lista usando os índices negativos, ou seja, o -1===

===Obs 2: ter um pouco de cuidado, pois com entradas grandes vai ser necessário um grande processamento para mover cada elemento uma posição para a frente===

*  É interessante que em casos e aplicações de listas só sejam alterados elementos no final dela, adições e remoções.

-  Método append adiciona elementos ao final da lista

```Python
lista.append("A")
lista.append(True)
```

-  O método pop serve como inverso do append e remove o último elemento presente na lista.

```Python
lista = [1, 2, 3, 4]
lista.pop()
print(lista)   # [1, 2, 3]
```

Além de remover, é importante lembrar que o pop retorna um valor, nesse caso o valor que foi removido da lista.

```Python
valor_removido = lista.pop()
print(valor_removido)    # 4
```

Outra observação importante é que o pop aceita argumentos que se referem a o índice do iterável, ou seja:

```Python
lista = [1, 2, 3, 4]
lista.pop(2)
print(lista.pop(2))    # Remove o elemento do índice dois
```

-  Método insert serve para inserir um elemento em um determinado índice. Esse método recebe dois argumentos, sendo o primeiro o índice em que você quer inserir e o segundo sendo o valor que será colocado. 

```Python
lista = [1, 2, 3, 4]
lista.insert(2, True)
print(lista)           # -> [1, 2, True, 3, 4]
```

Um fato interessante é que se eu não sei o índice do último elemento, eu posso "inserir" um valor "muito grande" e se esse valor for maior que a quantidade de elementos, o insert vai inserir na última posição.  ===Obs: não recomendado===

-  Método extend serve para fazer concatenação de listas, porém, diferente de alguns outros métodos esse altera o próprio objeto, ou seja, ele não retorna nada ou um não valor **None**.  Segue abaixo o exemplo

```Python
l1 = [1, 2, 3]
l2 = [4, 5, 6]
l1.extend(l2)
print(l1)      # -> [1, 2, 3, 4, 5, 6]

l3 = l1 + l2
print(l3)      # -> [1, 2, 3, 4, 5, 6]
```

Quando fazemos o sinal de + significa que estamos criando uma nova variável e atribuindo a junção das listas a essa variável, enquanto que quando usamos extend, estamos modificando o objeto que chamou o método, (estamos juntando o objeto que chamou o método com o atributo).

===Obs 3: quando um método não retorna nada, ou *None* significa que o próprio objeto está sendo alterado e nada está sendo retornado. ===

---

Em tipos imutáveis quando atribuímos ou copiamos o valor para uma outra variável fazemos uma cópia por valor, ou seja, o valor propriamente dito é copiado. São *"coisas"* independentes. Entretanto, quando estamos trabalhando com tipos mutáveis fazemos copia por referência, ou seja, **tanto a primeira variável como a segunda vão acessar o mesmo local na memória que está o valor**. Dessa forma, toda modificação feita em v1 será refletida em v2. 

O esquema em: [[Referencias]] deixa isso mais claro. 

```Python
l4 = [1, 0, 0, 1]  
l5 = l4  
  
print(l4)  
l4.append(7)  
print(l4)  
print(l5)

# Resposta
# [1, 0, 0, 1, 7]
# [1, 0, 0, 1, 7]
```

Para realmente copiar uma lista de forma que elas fiquem independentes, usamos o método copy. 

===Obs 4: o copy só funciona para listas simples, ou seja, listas em que seus membros podem ser copiados. A partir do momento que eu tenho uma lista dentro de outra não é mais possível usar o copy===

-  Como listas são iteráveis podemos usar o for para percorrer a lista e obtermos cada um dos valores presentes. 

###### Desempacotamento e Tuplas

O desempacotamento de variáveis se refere a atribuição dos valores na estrutura de dados uma a uma, segue o exemplo. 

```Python
nomes = ["Maria", "Helena", "Luiz"]
nome1, nome2, nome3 = nomes
```

Dessa maneira, cada um dos nomeX, X = {1, 2, 3} vai ser uma variável para os valores que estão na lista nomes. 

Além disso, eu tenho a opção de pegar apenas alguns valores específicos e não todos. (quando não temos variáveis suficientes para preenchermos os valores da lista).

```Python
nome1, nome2 = ["Maria", "Helena", "Luiz"]
# Ocorre ValueError

nome1, nome2, nome3, nome4 = ["Maria", "Helena", "Luiz"]
# Ocorre ValueError
```

Para que não ocorra erros, eu devo escolher o elemento e especificar o que vai acontecer com o resto, para informarmos que se trata de um resto usamos o asterísco. 

```Python
nome1, *resto = ["Maria", "Helena", "Luiz"]
```

===Obs 5: quando temos uma variável que normalmente não será usada nós definimos como underlines, __ ===

```Python
nome1, *_ = ["Maria", "Helena", "Luiz"]
```

Por fim, se for necessário um segundo valor ao invés do primeiro, usamos um underlines antes da variável, segue o exemplo abaixo.

```Python
_, nome2, *_ = ["Maria", "Helena", "Luiza"]
print(nome2)            # -> Helena
```

- Tuplas são como Listas, porém a diferença é que são imutáveis. Formas abaixo de como criar uma tupla.

```Python
nome = 'Joao', 22, 7.12

# Outra forma é usar ()

nome = ("Joao", 22, 7.12)
```

Além disso, também podemos converter uma lista para uma tupla e uma tupla para lista.

-  enumerate é uma função em Python que enumera um iterável passando o iterável como argumento. 
-  A função retorna um iterator, sendo assim, podemos chamar o método next e ele vai mostrar o "próximo" valor. 

```Python
lista = ["Maria", "Helena", "Luiz"]
lista.append("João")

lista_enumerada = enumerate(lista)
print(next(lista_enumerada))              # -> (0, "Maria")
```

Colocando isso em um for, como fizemos enquanto estudávamos iterator, ele faz basicamente o ato de buscar o próximo valor. 

```
(0, 'Maria')
(1, 'Helena')
(2, 'Luiz')
(3, 'João')
```

===Obs 6: é sempre bom usar um iterator no for mesmo para que ele sempre crie um novo, pois quando um iterator percorre toda a estrutura o ponteiro "aponta" para fora e não retorna para o inicio para ser executado em outro for, por exemplo. 

> O correto seria:

```Python
for item in enumerate(lista):
	print(item)
```

O enumerate basicamente interliga cada valor de dentro do iterável a um índice e devolve isso em formato de tupla, como vimos no penúltimo exemplo acima. 

===Obs 7:  utilizando o parâmetro start podemos definir de onde a enumeração irá começar.

Sintaxe para usar enumerate e obter os  índices e nomes. 

```Python
for indice, item in enumerate(lista_enumerada, start=1):
	print(indice, item)
```
