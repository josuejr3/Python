
##### For

O laço **for** normalmente é usada para quando sabemos até onde vai o que queremos contar ou repetir. 

A estrutura do **for** usa uma variável de controle

```Python
texto = "Python"

for letra in texto:
	print(letra)
```

Nesse caso, a variável letra corresponde a variável de controle, lê-se *"Para cada letra em texto"*

-  A função range(start, stop, step)

A função range requer que pelo menos um parâmetro seja passado. Quando somente um é passado é o start, se dois são passados temos o start e stop que é basicamente de onde começa até onde vai, e por fim o step que é o passo, ou seja, o intervalo entre unidades. 

```Python
numeros = range(10)
#consideramos o inicio sendo 0 e o final sendo 9, o total de elementos é 10
```

```Python
numeros = range(5, 10)
#consideramos o inicio sendo 5 e o final sendo 9, o total de 5 elementos.
```

```Python
numeros = range(5, 10, 2)
#consideramos o inicio sendo 5, o final sendo 9 e pulando a cada 2 elementos.
```

A função cria como se fosse um "campo" ou "alcance" que pode ser percorrido. 

==Obs: o step pode ser negativo, *PORÉM* é importante verificar os limites, pois se for de 0 até 10 não há como o for *"voltar"* para o -1, -2....===

> Como o for funciona por debaixo dos panos

O for possui as seguintes estruturas

-  Iterável: pode ser uma string, um range, uma lista, etc...
-  Iterador: é quem sabe entregar um valor por vez
-  next: é quem recebe o próximo valor
-  iter: é quem recebe o iterador. 

A função iter() retorna o iterador de algum iterável. 

```Python
texto= iter("Luiz") # __iter__()
print(texto)
```

A função next() retorna o próximo elemento do iterável

```Python
print(texto.__next__())
print(texto.__next__())
print(texto.__next__())
print(texto.__next__())
```

Após finalizado a quantidade de valores, ele retorna um erro pois o "apontador" não sabe mais para onde aponta é como se fosse um *null* do C/C++.

```Python
while True:
	texto = "Luiz"
	iterador = iter(texto)
	try:
		letra = next(iterador)
		print(letra)
	except StopIteration:
		break
```

-  O que aprendemos que pode ser misturado com o while, também pode ser usado junto com o for. 

	 -  break
	 -  continue
	 -  else

Exemplo:

```Python
for i in range(10):  
    if i == 2:  
        print("i é 2, pulando...")  
        continue  
    if i == 8:  
        print("i é 8, seu else nao vai executar")  
        break  
    for j in range(1, 3):  
        print(i, j)  
else:  
    print("for completo com sucesso")
```
