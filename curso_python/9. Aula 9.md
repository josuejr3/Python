##### Imprecisão de números decimais

Valores em ponto flutuante em Python são imprecisos, segue abaixo.

```Python
numero1 = 0.1  
numero2 = 0.7  
numero3 = numero1 + numero2  
print(numero3)      # -> 0.7999999999 Valor impreciso
```

Porém, quando formatamos usando f-strings o valor já vem "arredondado"

-  DOULE-PRECISION FLOATING-POINT FORMAT IEEE 754 -> print(f"{numero:.2f}")

===Ok, mas como podemos corrigir isso?===

A primeiro forma nós já vimos, que é usando a formatação com f-strings

-  A segunda forma é nós utilizarmos a função round()

```Python
print(round(numero3, 2))
```

O argumentos passados são o número a ser arredondado e quantas casas vão ter no final.

-  A terceira forma, é usando um módulo específico do Python chamado *Decimal*. Nesses casos, fazemos alguns ajustes, como por exemplo, o argumento é passado como string e não float e também devemos arredondar com round para a quantidade de casas desejadas.
  
  ````Python
numero1 = decimal.Decimal("0.1")  
numero2 = decimal.Decimal("0.7")  
numero3 = numero1 + numero2  
print(round(numero3, 2))
````

##### Método split e join

-  O método split divide a string e retorna uma lista com o conteúdo dela, por padrão a lista é dividida em espaços, porém, esse caractere pode ser alterado.

```Python
frase = "Olha so que coisa interessante"  
  
# Metodo split divide a string baseada em um caractere e transforma em lista  
frase = frase.split()  
print(frase)

# Resposta -> ['Olha', 'so', 'que', 'coisa', 'interessante']
```

-  ===Obs: com expressões regulares conseguimos fazer um split mais refinado.===

O argumento não precisa necessariamente ser um caractere, pode ser uma sub-string.

-  Além do método split() ser muito importante, temos também o método strip(), lstrip() e rstrip(). Os métodos servem para remover os espaços nas laterais da string, no lado esquerdo e no direito, respectivamente.

-  O método join() serve para unir iteráveis. 

```Python
frases_unidas = "SEPARADOR".join('abc')  
print(frases_unidas)
```

Por padrão, o separador vem nulo, "", porém, eu posso usar qualquer caractere para ser usado como separador. Nesse caso, se eu não passo um segundo argumento ele vai separar entre os elementos do iterável. Sendo assim o resultado do código acima será de:

```Python
# aSEPARADORbSEPARADORc
```

##### Interpretador Python

Anteriormente, nós tinhamos visto um comando de terminal usado para verificar a versão o Python instalada no computador.
```Python
Python --version
```

Outro comando bastante utilizado é de ajuda

```Python
Python --help
```

Ao executar esse comando, várias informações vão ser exibidas no terminal, as informações se tratam de comandos semelhantes ao próprio version, ou o help, que também podem ser usados no terminal.

-  Podemos executar módulos Python direto pelo terminal, lembrando que módulos Python são os nossos programas.

```cmd
python "/Users/..."   # Python usando o caminho
python modulo.py      # chamando somente pelo nome.py
```

-  python -u (unbuffered): O buffer funciona como um pequeno espaço da memória que é usado para armazenar previamente o que vai ser "jogado" na tela.

	 Esse comando é usado quando não queremos salvar no buffer e jogar diretamente a informação na tela.

-  python -m mod (lib mod como script): Executa uma biblioteca do Python como script.

	 Exemplo é a biblioteca venv, que serve para criar ambientes virtuais. Em alguns casos ela é instalada separadamente (Linux).
	O exemplo abaixo mostra a criação de um ambiente virtual chamado "nome_qualquer".

```cmd
python -m venv nome_qualquer
# "Python execute a biblioteca venv como script e crie o ambiente virtual nome_qualquer"
```

O pasta de ambiente virtual trás varias outras que servem para ativar ele mesmo, (dentro da pasta bin).

-  python -c "comando": Nesse caso, o python executará um comando direto do terminal sem ter a necessidade de um script.

```cmd
python -c 'print("oi")'
>> oi
```

===Obs: em python podemos usar ";" igual outras linguagens para ter uma quebra de linha no código. Porém, não é tão semelhante e visualmente confortável. 

```Python
print("oi");print("tchau")
```

-  python -i mod.py: Aqui o Python entra no modo iterativo, porém, nesse caso o modo iterativo será de um módulo/script pronto.

```cmd
python -i mod.py
```

Essas informações são as mais básicas, para mais detalhes consultar o "--help" onde haverá todos os comandos disponíveis.

##### Desempacotamento em chamadas de funções

Podemos desempacotar variáveis da seguinte forma.

```Python
a, b, c = ["Maria", "Helena", 1, 2, 3, "Eduarda"]
```

Caso a lista seja maior que as variáveis podemos ainda utilizar o """ponteiro""" que armazena o resto.

```Python
a, b, *_, final = ["Maria", "Helena", 1, 2, 3, "Eduarda"]
# a = "Maria"
# b = "Helena"
# *_ = [1, 2, 3]
# final = "Eduarda"
```

Também poderia pegar o antepenúltimo.

```Python
lista = ["Maria", "Helena", 1, 2, 3, "Eduarda"]
print(*lista)
print("Maria", "Helena", 1, 2, 3, "Eduarda")

# Maria Helena 1 2 3 Eduarda
```

É como se cada um dos itens fosse passado para o print e assim eles fossem printados.

##### Operação ternária em Python

Operação ternária, nada mais é, como o próprio nome já diz, uma operação que envolve três "objetos" e pode ser escrita em uma única linha de código. 

-  A condição que será avaliada;
-  O que acontece se ela for verdadeira;
-  O que acontece se ela for falsa.

Segue abaixo o exemplo da sintaxe.

```Python
# <valor> if <condicao> else <outro_valor>
print("valor" if True else "outro valor")
```

Outro exemplo de uso já atribuindo em variável

```Python
digito = 9  
novo_digito = digito if digito <= 9 else 0  
print(novo_digito)
```

===Obs, na expressão ternária eu posso usar vários ifs, porém, não é o recomendado.===
##### Spoilers - expressões regulares

No caso da atividade de validação de CPF. Como só nos interessa números, significa que eu quero substituir qualquer coisa que não for um número. 

```Python
# Importando o módulo de expresões regulares
import re

# Fica assim
cpf = re.sub(r'[^0-9]', '', "746.824.890-70")

```

Outra biblioteca que podemos usar para encerrar o Python é a sys.

```Python
import sys

# Encerra o Python
sys.exist()
```

Seguindo o exemplo de validador de CPF, nós também podemos criar um gerador de CPF. A diferença consiste na entrada, que não será mais a partir do usuário. Utilizaremos a biblioteca *random* que gera números aleatórios.

```Python
import random

# Gerando um número aleatório entre 0 e 9
print(random.randint(0, 9))
```
