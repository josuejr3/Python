##### Recursividade e Funções Recursivas

Funções recursivas são funções que chamam a si mesmas. Elas são úteis quando temos um problema grande e podemos dividir o problema em partes menores.

As funções recursivas devem ter as seguintes características:

-  Um problema que possa ser dividido em partes menores;
-  Um caso recursivo que resolve um pequeno problema;
-  Um caso base que para a recursão
-  Exemplo de problema: fatorial de um número n qualquer.

```Python
def recursiva(inicial=0, fim==10):
	# Caso recursivo
	# Contar até o final
	inicio += 1
	return recursiva(inicio, fim)
```

O caso base, é o caso de parada e ele é importante de ser definido para evitarmos de ocasionar algum "stack overflow" que funciona como se fosse uma "boneca russa", ou seja, uma chamada de função dentro da outra. 

Em resumo, é como se cada chamada de função fosse "mais interna" sem ter um fim. 

A melhor maneira de corrigir o erro que está no código acima (ele ocasiona stack overflow) é utilizando um caso base ou caso de parada.

```Python
def recursiva(inicial=0, fim=10):  
    # Caso recursivo  
    # contar até chegar ao final  
    if inicial >= fim:  
        return fim  
  
    inicial += 1  
    return recursiva(inicial, fim)  
  
print(recursiva())
```

Quando finalmente a minha função encontra o caso base, ela vai retornando os valores e removendo as chamadas da call stack (pilha de chamadas)

Em Python, o limite de recursão é de 1000, ou seja, mais do que isso a linguagem não suporta e lança uma exceção de "RecursionError" no terminal (mesmo que o programa esteja correto), como o caso da contagem de 1 a 1000.

Para resolver isso eu posso alterar o limite de recursão usando a biblioteca sys. 

```Python
import sys
sys.setrecursionlimit(1004)
```
