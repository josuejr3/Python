## Dicionários

Dicionários, em Python é uma estrutura de dados do tipo par, pois contém, uma "chave" e para cada uma tem um "valor". 

- ===Chaves podem ser consideradas como índice que vimos na listas, por exemplo. Além disso, elas podem ser de tipos imutáveis, como: str, int, float, bool, tuple e etc.===
-  ===O valor pode ser de qualquer tipo, incluindo o próprio dicionário.===
-  A forma de representar é a partir de chaves *{* *}* ou então a palavra chave *dict*

		Revisão de tipos mutáveis e imutáveis. 

| Mutável  | dict, list                   |
| -------- | ---------------------------- |
| Imutável | str, int, float, bool, tuple |

```Python
# Exemplo de um dicionário que representa uma pessoa
pessoa = {
		  "nome": "Luiz Otavio",
		  "sobrenome": "Miranda",
		  "idade": 18,
		  "altura": 1.8,
		  "endereço":[
			  {"rua": "tal tal", "numero": 123},
			  {"rua": "outra rua", "numero": 321},
		  ]
}
```

Os dicionários ajudam na visualização de dados. Tomando como exemplo a situação de representação de uma pessoa, caso fossemos utilizar uma lista para colocar todas as características ficaria complicado de encontrar uma em específico, pois os índices são numéricos.  Usando o dicionário conseguimos facilitar o trabalho definido índices "personalizados" para cada elemento que queremos.

```Python
pessoa["nome"] = "Luiz Otavio"
```

-  No exemplo acima temos uma pessoa representada através de um dicionário. O índice/chave "endereço" tem como valor vários endereços. Esses endereços se encontram dentro de uma estrutura de dados mutável (lista) e essa lista é também de dicionários que representam os endereços com suas características. 

-  Para acessar um membro, como vimos anteriormente, basta que eu faça igual no restante das outras estruturas, passe os ==colchetes== *[]*  e dentro deles a chave desejada.

O dicionário propriamente dito não é iterável, porém o Python consegue usar as chaves e com isso podemos usar laços de repetição.

```Python
for key in people:  
    # Coletando a chave e o valor dela  
    print(key, people[key])
```

A forma de adicionar elementos no dicionário é diferente da que vemos em listas. Não há um método, apenas adicionamos a chave "manualmente".

```Python
pessoa = {}
# dicionário zerado, sem nenhuma chave

pessoa["nome"] = "Luiz Otavio"
```

- Não podemos acessar chaves que não existem no dicionário, o Python lançará uma exceção. 

-  Além disso, podemos usar chaves dinâmicas para acessar os valores. 

```Python
pessoa = {}

chave = "nome_completo"

pessoa[chave] = "Luiz Otávio"
lista = []

print(pessoa[chave])
```

Da mesma maneira que usamos o operador de atribuição para adicionar uma nova chave e valor ao dicionário, podemos usar novamente para alterar o valor passado. 

```Python
key = "Programa de TV"  
people[key] = "Sons Of Anarchy"  
print(people[key])  # Printa Sons of Anarchy
  
people[key] = "Twin Peaks"  
  
print(people[key])  # Printa Twin Peaks
```

-  Para apagar uma das chaves usamos o comando *"del"* assim como em listas. 

```Python
del people["Pet"]
```

Dessa maneira, vimos como criar chaves, editar chaves e deletar chaves **(CRUD)** ===(lembrando que todas acompanhadas pelos seus valores). ===

-  Se quisermos verificar se uma chave existe, ou se formos fazer uma condicional de verificação de chaves, ela lançará uma exceção do tipo KeyError. 

	Para resolver esse problema, podemos usar ou o "try-except" ou então usar um método especial que retorna se a chave existe ou não no dicionário, método "get"

```Python
if pessoa.get("Pet", None):
	print("Existe")
```

	Por padrão esse método retorna None, porém eu posso passar outra coisa no lugar do None, como por exemplo, "Não existe".

##### Método úteis usados em Dicionários no Python.

A seguir alguns métodos mais utilizados em dicionários no Python.

-  len() - Retorna a quantidade de chaves
	Não é um método exclusivo de dicionários, ou seja, não está nos dicionários, porém, não usamos como um método. 

	===Podemos usar o "dunder" que é o método com underline .__ len__( )===

	O len chama esse método

-  keys() - iterável com as chaves

	 Retorna as chaves do dicionários, no sentido literal ele retorna um *"dict_keys"* que é um iterável, porém, podemos fazer a coerção para outro iterável, como por exemplo, listas e tuplas. 

	É bem semelhante com tuplas e listas, porém não são, dessa forma não podemos usar índices para obter os valores, ===primeiro deve-se fazer a coerção===

	```Python
	# 1  
	for key in people.keys():  
	    print(key, end=" ")  
	print("\n")  
	# 2  
	for key in people:  
	    print(key, end=" ")  
	# 1 e 2 são iguais
	```

-  values() - iterável com os valores

	É semelhante ao .keys(), porém nesse caso ele retornará um *"dict_values"* e retorna os valores, que também é semelhante a uma lista e tupla, porém não podemos "indexar", é necessário fazer a coerção para lista ou tupla. 

	```Python
	for value in people.values():  
	    if type(value) is list:  
	        for element in value:  
	            print(element)  
		print(value)	
```

-  items() - iterável com chaves e valores

	Semelhante aos outros, .items() retornará um *"dict_items"* que também pode ser convertido. Nesse caso, ele retorna tanto a chave, como também o valor correspondente.  Como cada elemento será uma tupla com a chave e o valor, o for vai funcionar como se fosse o *"enumerate"* que estudamos anteriormente. 

```Python
print(type(people.items()))  
print(type(list(people.items())[0]))  
  
# semelhante ao que vimos no enumerate  
for chave, valor in people.items():  
    print(chave, valor)
```

-  setdefault - adiciona um valor se a chave não existe

	O setdefault tem um funcionamento semelhante ao que vimos no .get() e ajuda a não cairmos em uma exceção. Quando estudamos o caso do get, vimos que ele é usado para verificar a existência de uma chave no dicionário e se essa chave não existir ele retorna *None* ou qualquer outra coisa que o programador deseje. O setdefault faz quase a mesma coisa. 
	
	O setdefault pode ser usado para obter um valor de uma chave específica. Se a chave não existir, ele cria uma com o valor passado, segue o exemplo. 

```Python
people = {
	"nome": "Joao",
	"idade": 18,
}

# Verificando a chave "Pet". (Não existe)
people.setdefault("Pet", "Dog")

# Nessa situação, ele verifica se o dicionário possui a chave Pet
# Se existir, ele não faz nada, se não existir, ele irá criar a chave
# E vai atribuir o valor do segundo parâmetro. 
```

-  copy - retorna uma cópia rasa (shallow copy)

	O método copy de dicionários, assim como o de listas, faz uma shallow copy, ou seja, uma cópia rasa do dicionário. Assim como nas listas, quando fazemos:

```Python
d1 = {
  "c1": 1,
  "c2": 2,
  "l1": [1, 2, 3]
}
d2 = d1
```

> Tanto d1, como d2 apontam para o mesmo local na memória.  Então, se mudarmos o valor em d1, o valor também será alterado em d2. 

> Aí que entramos no conceito de **shallow copy** ou **cópia rasa**

>**shallow copy** é uma cópia rasa e acontece quando usamos o método copy. Nesse caso, ele cria um novo dicionário e copia todos os dados que são imutáveis para o novo dicionário. Porém, se dentro do dicionário tivermos qualquer valor mutável ele não vai fazer a cópia, ele irá fazer com que os dois dicionários, agora distintos, apontem para o mesmo objeto imutável, nesse caso, a lista *l1*. 

```Python
d1 = {  
    "c1": 1,  
    "c2": 2,  
    "l1": [1, 2, 3],  
}  
# Apontam para o mesmo local da memória.  
d2 = d1.copy()  
  
d2["c1"] = d1["c1"] * 2  
d2["c2"] = d1["c2"] * 2  
  
print(d1["c1"], d2["c1"])  
print(d1["c2"], d2["c2"])  
  
print(d1["l1"], d2["l1"])  
d1["l1"][0] = 1000 # ambos os dicionários vao ser mudados  
print(d1["l1"], d2["l1"])
```

> Para corrigir isso, somente através de um módulo Python específico, chamado de copy

```Python
import copy 

d2 = copy.deepcopy(d1)  # Copia profunda
d2 = copy.copy(d1)      
```

-  get - obtém uma chave

	Retorna um valor escolhido pelo programador ou None *(padrão)* e é usado para verificar a existência de uma chave. 

```Python
p1 = {
	  "nome": "Josue",
	  "idade": 23,
	  "pet": "Dog",
}

# Com padrão None
if p1.get("pet") is None:
	print("Não tem essa chave")
else: 
	print("OK")

print(p1.get("pet", "Chave não existe"))

```

- pop - apaga um item com a chave especificada (del)

	O pop é semelhante ao que vimos na lista, ele remove um item do iterável e retorna ele. 

```Python
p1 = {
	  "nome": "Luiz",
	  "sobrenome": "Miranda",
}
variavel = p1.pop("nome")
# Remove a chave nome do dicionário e o valor que estava na chave é  armazenado em uma variável. 
```

-  popitem - apaga o último item adicionado

	A diferença do popitem para o pop é que o pop remove o elemento de um dicionário passando a chave que se quer remover e retorna o valor desse elemento. Já o popitem remove o último elemento do dicionário, sendo assim, no caso abaixo quem será removido vai ser sobrenome, ele também retorna a última chave que estava no dicionário. 

```Python
p1 = {
	  "nome": "Luiz",
	  "sobrenome": "Miranda",
}
variavel = p1.popitem()
# variavel vai ser uma tupla contendo  par chave e valor que era o último no meu dicionario. 
# Além disso, o valor também foi removido do dicionário, restando apenas a chave nome
```

-  update - atualiza um dicionário com outro.

	 O método update como próprio nome já diz, serve para atualizar um dicionário, como por exemplo, acrescentar novas chaves e valores ou até alterar os que já estão contidos. Segue abaixo exemplo da notação do método. 

```Python
p1 = {
	  "nome": "Luiz",
	  "sobrenome": "Miranda",
}

# Forma de usar o update 1
p1.update(
	{
		"nome": "Josue",  # altera o valor da chave nome para Josue
		"sobrenome": "Ferreira", # altera o valor da chave sobrenome
		"idade": 23, # cria uma chave de nome idade e com valor 23
		"serie": "Sons Of Anarchy", # cria uma chave de nome serie e valor
	}
)

# Forma de usar o update 2 - Argumentos nomeados

p1.update(pet="dog", cor="preto")

# Forma de usar o update 3 - usando tupla/lista
# esse caso só funciona se for uma estrutura bidimensional, tupla de tuplas, lista de listas, tupla de listas...
tupla = ("chave", "valor"), 
p1.update(tupla)
print(p1)
```

## Set - Conjuntos

Os conjuntos em Python são os mesmos conjuntos que aprendemos na matemática. 

-  Eles são representados graficamente pelos diagramas de Venn
-  Sets em Python são mutáveis, porém, só aceitam elementos imutáveis.

	Criando um set

```Python
# set(iterável) ou {1, 2, 3}
# set_vazio = set()
# set_vazio_2 = {}                não é um set, é um dicionário
```

-  Conjuntos são eficientes para garantir/remover valores duplicados de iteráveis. 
	-  Eles **NÃO** possuem indexes;
	-  Eles **NÃO** garantem ordem;
	-  Eles **SÃO** iteráveis, suportam operações com (for, in, not in).

-  Colocando iteráveis diretamente no conjunto, ele itera sobre cada um dos elementos. 

```Python
s1 = set("Luiz")
print(s1, type(s1))

# O print vai ser: {'z', 'L', 'i', 'u'} <class 'set'>
# Não leva em consideração a ordem
```

- São bons para remover valores duplicados de iteráveis. 

```Python
s1 = {1 ,2, 3, 3, 3, 3, 3, 3, 4}  
print(s1)
# {1, 2, 3, 4}
```

```Python
l1 = [1, 2, 3, 4, 4, 4, 5, 6, 6]
s1 = set(l1)
l2 = list(s1)
print(l2)
# [1, 2, 3, 4, 5, 6]
```

===Obs: atenção que o problema pode ser de não ficar na mesma ordem que precisamos, já que essa estrutura de dados não leva em consideração a organização===

===Objetos mutáveis não são aceitos dentro do set, como listas e dicionários, por exemplo===

```Python
s1 = s1 = {1, 2, 3, [123]}
print(s1)
# Erro unhashable type
```

Como não possuem índices, os sets podem ser mais rápidos para alguma determinada ação que queiramos fazer.

##### Métodos importantes

-  add
Esse método serve para adicionar um novo elemento ao conjunto (lembrando que em conjuntos a ordem não é específica e pode alterar a cada execução)

```Python
a3 = set()  
  
# Adicionando elemntos noo set  
a3.add(1)  
a3.add(90)  
print(a3)  
a3.add(0)  
print(a3)
```

-  update
O método update serve de forma semelhante ao add e pode ser usado também para adicionar elementos ao conjunto.

```Python
a3.update("Olá mundo") # insere no set, porém, itera toda a string
s3.update(("Olá mundo"))

# método update para modificar o conjunto  
a3.update(("Ola mundo",))  # Como adicionar strings completa, sem iterar
# caractere por caractere
print(a3)
```

-  clear
Esse método limpa o set e remove todos os elementos que estão presentes nele. 

```Python
print(a3)
a3.clear()
print(a3)
```

-  discard
O método discard serve para remover um elemento do nosso conjunto, porém ele não usa o índice ===lembrar que sets não possuem índices=== e todos os elementos são únicos, dessa forma, basta passar o elemento que se deseja remover

```Python
print(a3)
a3.discard("Olá mundo")
print(a3)
```

##### Operações entre conjuntos

Assim, como na matemática os conjuntos possuem operações que podem ser realizadas, no Python não é diferente. 

-  União -  **( | )**
A união é basicamente um novo conjunto que contém os elementos dos conjuntos que estão unidos. 

```Python
c1 = {1, 2, 3}
c2 = {1, 3, 7}

# Usando pipe |
c3 = c1 | c2

# Usando método
c3 = c1.union(c2)

print(c3)           # c3 = {1, 2, 3, 7}
```

-  Intersecção - **( & )**
A interseção é um novo conjunto que contém apenas os elementos que estão presentes nos dois conjuntos. 

```Python
c1 = {1, 2, 3}
c2 = {1, 3, 7}

# Usando o e comercial &
c3 = c1 & c2

# Usando método
c3 = c1.intersection(c2)

print(c3)           # c3 = {1, 3}
```

-  Diferença - **( - )** 
Nesse caso, a ordem de operação muda. A diferença gera um novo conjunto com todos os elementos do primeiro conjunto, menos os elementos do segundo conjunto

```Python
c1 = {1, 2, 3}
c2 = {1, 3, 7}

# Usando o hífen -
c3 = c1 - c2
c4 = c2 - c1

# Usando método
c3 = c1.difference(c2)
c4 = c2.difference(c1)

print(c3)           # c3 = {2}
print(c4)           # c4 = {7}
```

-  Diferença Simétrica - **( ^ )**
Por fim,  o último caso retorna um conjunto formado pelo elementos que são *"exclusivos"*, ou seja, estão somente em seus conjuntos. 

```Python
c1 = {1, 2, 3}
c2 = {1, 3, 7}

# Usando ^ (a ordem não importa)
c3 = c1 ^ c2
print(c3)                         # {2, 7}
```

===Aplicação:=== uma aplicação bastante interessante usando sets, é de um jogo da forca, como vimos antes. Como cada letra é uma tentativa, e o set não repete elementos, podemos adicionar cada tentativa (letra) em um set e a partir disso fazer a verificação.

```Python
# Exemplo de uso set

letras = set()

while True:
	letra = input("Digite: ")
	letras.add(letra)
```
