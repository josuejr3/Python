##### Operadores matemáticos


-  Adição: 10 + 10
-  Subtração: 10 - 10
-  Multiplicação: 10 * 10
-  Divisão com resto: 10 / 10
-  Divisão inteira: 10 // 10
	-  Nesse caso, o resultado é **truncado**, ou seja, ele é "cortado" e as casas decimais não aparecem
-  Resto da divisão: 10 % 10
-  Exponenciação: 10 \*\*2

> **ELIPISIS** é definido como "..." e é um placeholder e usado para substituir um local do código que ainda não está certo sobre o que ele faz, como se fosse um tapa buraco.

-  fstrings nos disponibilizam fazer uso de variáveis dentro da string usando as chaves {}
-  Em caso de tipos float eu posso definir a quantidade de casas decimais utilizando o seguinte

```Python
altura:.2f
```

-  Outra maneira de fazer formatação de strings é usando o método format.

```Python
a = 'A'
b = 'B'
c = 'C'
formato = ''.format(a, b, c)
print(formato)

# Para exibir os valores basta eu colocar chaves
formato = 'a={} b={} c={}'.format(a, b, c)
```

===Obs: além disso, posso definir a quantidade de casas decimais usando o===  **:.2f**

-  A quantidade de argumentos deve ser igual a quantidade de chaves.
-  Alternativamente eu posso pegar por índices, ou seja, dentro das chaves, substituir por um índice do argumento

```Python
formato = 'a={0} b={1} c={2:.2f}'.format(a, b, c)
```

===Nesse caso eu não dependo da ordem==

-  Parâmetros nomeáveis - argumentos default;

```Python
formato = string.format(a, b, nome3=c)
```
