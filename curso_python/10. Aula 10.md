##### Funções

Funções são trechos de código para replicar determinadas ações ao longo do código principal. Elas podem receber valores para os parâmetros (argumentos) e retornar um valor específico. Por padrão, funções Python retornam **None** (nada).

-  A função print é uma função base já do Python
- ===Obs: não é recomendado começar nomear funções com letras maiúsculas.==
-  Ao chamar uma função, se ela possuir parâmetros indeterminados, ou seja, que não possuem nenhum valor padrão, é necessário passar esses valores, do contrário, ocorrerá um erro. 

```Python
def imprimir(a, b, c):

```

===Obs: parâmetros, é a variável da função, argumento é o valor que nós passamos. ===

```Python
def imprimir(a, b, c):  
    # print("Varias 1")  
    # print("Varias 2")    # print("Varias 3")    print(a, b, c)  
  
imprimir(1, 2, 3)  
imprimir(4, 5, 6)
```

-  Argumentos/Parâmetros ***Default***

Além disso, posso ter argumentos padrão, nesses casos, se a função chamada mas nenhum valor for passado como como argumento, haverá um valor na própria função que servirá como base para execução, ou seja, um valor padrão caso não seja substituído.

Exemplo

```Python
def imprimir_nome(nome = "Sem nome")
	print(f"Nome = {nome}")

imprimir_nome("Josue")                   # -> Josue
imprimir_nome()                          # -> Sem nome
```

Agora vamos falar um pouco sobre os tipos de argumentos em funções Python. Existem dois tipos padrão.

-  ===Argumento nomeados===
- ===Argumentos não nomeados ou posicional===

```Python
# Definição da função
def soma(x, y):
	print(x + y)

```

Outro caso

```Python
def soma(x, y):
	print(x + y)

```

No caso acima, como a própria função soma não retorna nada, ela somente printa, ao chamarmos o print com a função soma dentro ela irá printar o retorno de soma, que na realidade é o ***None***.

Modo correto

```Python
def soma(x, y):
	print(x + y)

soma(1, 2)
```

Nesse caso, os argumentos passados para **x** e  **y** são posicionais, pois levam em consideração a ordem que estão distribuídos. 

===Obs: nesse caso a ordem não importa tanto, porém, é importante verificar a situação do problema para saber se a ordem de parâmetros e argumentos não vai impactar no resultado esperado===

===Obs: quando chamamos funções podemos mesclar e chamar uns nomeados e outros não, porém, isso NÃO É RECOMENDADO. Ou chama tudo nomeado, ou chama tudo não nomeado. 

Funciona como em C/C++, a partir do momento que você nomeia um argumento, todo o restante depois dele deverá também ser nomeado. 

```Python
# ERRO
soma(1, y=2, 5)

# CORRETO
soma(1, 5, y=2)
```

Todo o restante após y na situação 2 deve ser nomeado. 

-  Argumentos / Parâmetro Default exemplo:

```Python
def soma(x, y, z=0):
	print(x + y + z)
```

Nesse caso, se eu não passar nenhum valor para o parâmetro Z, o valor dele será 0.

Levando em consideração que 0 é um valor Falsy, podemos ajustar a função da seguinte maneira.

```Python
def soma(x, y, z = 0):
	if z:
		print(f"{x=} {y=} {z=}", x + y + z)
	else:
		print(f"{x=} {y=}", x + y)
```

Para melhorar isso eu ainda poderia ao invés do 0 usar o None. 

```Python
def soma(x, y, z=None):
	if z is not None:
		print(f"{x=} {y=} {z=}", x + y + z)
	else:
		print(f"{x=} {y=}", x + y)
```

##### Escopo de Variáveis, Global e Local

Escopo é o local onde o código pode atingir. Existem dois tipos de escopo em Python.

-  Escopo Global;
-  Escopo Local.

O global, como o próprio nome já diz, é o escopo em que todo o código é alcançável, já o local é onde apenas nomes do mesmo local podem ser alcançados.

-  *O que eu faço dentro da função, fica na função*

```Python
def escopo():
	x = 1
	print(x)

escopo()
```

No exemplo acima, a variável *x* está definida dentro do escopo apenas da função, ou seja, um escopo local. Sendo assim, não será possível alterar o valor fora da função.

Porém se eu fizer a modificação abaixo:

```Python
x = 1

def escopo():
	print(x)

escopo()
```

O código rodará tranquilamente, já que o *x* foi definido fora da função e é uma variável *global*. Só não seria válido se o *x* fosse definido após a função.

-  Analisando um pouco mais sobre escopos

```Python
x = 1

def escopo():
	x = 10

	def outra_funcao():
		y = 2
		print(x, y)

	outra_funcao()
	print(x)

escopo()
```

No caso acima, eu teria acesso ao x tanto pela função *escopo*, como também, pela *outra_funcao*. Porém, eu não tenho acesso a função *outra_funcao* fora da função *escopo*.

-  Eu só posso acessar dados mais externos, os mais internos são **BLOQUEADOS**.
-  Para que *outra_funcao* seja executada, é necessário que *escopo* seja executada.

```Python
x = 1  
  
def escopo():  
    x = 10  
  
    def outra_funcao():  
        y = 2  
        print(x, y)  
    outra_funcao()  
    print(x)  
  
print(x)  
escopo()  
print(x)
```

O valor de *x* no último print continuará sendo de 1, pois o *x* dentro da função escopo é como se fosse uma "cópia".

-  Nesse caso, as variáveis *x* possuem os mesmos nomes, porém, como estão em escopos diferentes, elas são variáveis diferentes.

-  Caso eu queria tornar uma variável global, eu posso fazer o seguinte. 
  
```Python
x = 1  
  
def escopo():  
	global x
    x = 10  
  
    def outra_funcao():  
	    global x
        y = 2  
        print(x, y)  
    outra_funcao()  
    print(x)  
  
print(x)  
escopo()  
print(x)
```

Isso significa, que no escopo da função *escopo*, o *x* é global, ou seja, a mesma variável que está definida fora da função.

===Em resumo, a palavra *global* faz a variável do escopo externo ser a mesma do interno.===

| Funções             | Acessa                                                                       |
| ------------------- | ---------------------------------------------------------------------------- |
| main/arquivo/modulo | todo o arquivo, exceto interno de funções                                    |
| escopo()            | acessa todo o arquivo, exceto variáveis dentro de funções internas           |
| outra_funcao()      | todo que é externo a ela, se houverem funções internas a ela, ela não acessa |
-  Sempre vamos acessar o que está mais próximo do nosso escopo.

===Obs: É UMA MÁ PRÁTICA DE PROGRAMAÇÃO MANIPULAR VARIÁVEIS GLOBAIS EM FUNÇÕES.===

-  Retorno de Funções

```Python
variavel = print("Luiz")
# Vai aparecer Luiz

# Se eu printar a variavel
print(variavel)    # Vai printar o valor None, pois a função printa
                   # Não retorna nada
```

- *None* é um não valor.

O retorno significa que algum dado que está na função ou que foi modificado por ela, pode ser salvo para usar posteriormente.

```Python
def soma(x, y):
	print(x + y)

soma1 = soma(2, 2)
```

Nesse caso o valor não será somado e o resultado de soma1 será "None", pois a função não retorna nenhum valor para ser salvo, apenas exibe.  O correto, seria:

```Python
def soma(x, y) -> int:
	return x+y

soma1 = soma(2, 2)
```

Códigos feitos após o *return* não são considerados, todo o subprograma da função é parado e o valor é retornado.

-  As funções só tem um único return, e cada return só pode retorna um único valor que pode ser unidimensional ou não, ex: lista, tupla, inteiro...

```Python
def soma(x, y):
	if x > 10:
		return 10, 20 # retorno de uma tupla sem os colchetes
	return x + y
```

###### Empacotamento e desempacotamento de argumentos não nomeados

- args - significa que os argumentos são não nomeados
- * - quando usamos o asterísco significa que estamos fazendo (empacotamento e desempacotamento de argumentos)

Se uma função tem a necessidade de passar diversos argumentos (não nomeados) não é necessário colocar todos os parâmetros na função. 

```Python
def printa1(x):
	...
def printa2(x, y):
	...
def printaN(x, ..., n):
	...
```

Exemplo 'empacotando' todos os parâmetros em um "args*"

```Python
def soma(*args):

# *args é uma tupla, podemos converter para lista

	total = 0
	for numero in range(args):
		total += numero
	return total
```

>===Obs: Já existe uma função no Python que faz soma de elementos de um iterável, é a sum()=== 

Entretanto, como o sum() só aceita iteráveis, não poderiamos passar dois elementos puros. 

```Python
somados = sum(1, 2, 3, 4, 5, 6, 7, 8, 9)
# ERRO -> foram passados 9 parâmetros o correto seria definir a tupla antes

somados = sum((1, 2, 3, 4, 5, 6, 7, 8, 9))
```

Quando desempacotamos é como se espalhássemos os valores ao longo dos parâmetros.

===Em resumo, colocar o * em uma estrutura de dados linear, como a tupla desempacota para enviar  como parâmetros para uma função. ===

##### Higher Order Functions - Funções de Primeira Classe e Closure

Funções de primeira classe em Python significa dizer que elas podem ser usadas como qualquer outro tipo de dado.

```Python
def saudacao(msg):
	return msg
```

Sendo assim, podemos fazer uma função se encontrar em uma outra variável. Teremos uma nova variável *apontando* pro mesmo local de memória que nossa função real aponta.

```Python
def saudacao(msg):
	return msg

saudacao_2 = saudacao

v = saudacao("Bom dia")
print(saudacao_2("Oie"))    # Também da certo, saudacao_2 aponta pra o     mesmo lugar de memória que saudacao
print(v)
```

No caso acima eu não estou  chamando a função diretamente. Eu referencio a área da memória que a função "saudacao" se encontra a partir da variável "saudacao_2" e com isso eu posso usar a "nova função" do mesmo jeito que eu uso a principal.

A partir disso, também podemos ter funções que recebem outras funções como argumento e executem elas. 

```Python
def executa(funcao):
	return funcao()
``` 

Outra maneira

```Python
def saudacao(msg):
	return msg

def executa(funcao, msg):
	return funcao(msg)

v = executa(saudacao, "Bom dia")
```

```Python
def saudacao(msg, nome):  
    return f"{msg}, {nome}"  
    
def executa(funcao, *args):   # Empacotamento
    return funcao(*args)      # Desempacotamento
    
# v = saudacao("Bom dia")  
# print(v)  
  
v = executa(saudacao, "Bom dia")  
print(v)
```

Nesse caso, a função executa, chama a função saudacao que tem como parâmetros a msg e o nome, porém, executa só recebe dois parâmetros, então modificamos para executa receber apenas o nome da função e o restante servirá como argumento da função chamada (* **args**)

-  Higher Order Functions - Funções que podem receber e/ou retornar outras funções;
-  First-Class Functions - Funções que são tratadas como outros tipos de dados comuns (strings, inteiros, etc...)

-  **CLOSURE**

Closure pode ser entendido como fechamento

```Python
def criar_saudacao(saudacao, nome):
	def saudar():
		return f"{saudacao}, {nome}!"
	return saudar

s1 = criar_saudacao("Bom dia", "Luiz")
print(s1) # "Bom dia, Luiz!"

s2 = criar_saudacao("Boa noite", "Maria")
print(s2)

# Após o closure, quando ele já "retorna" a função
print(s1())   # Executando a função retornada
print(s2())   # Executando a função retornada
```

Para melhorarmos o código e evitar chamadas iguais de várias saudações, s1, s2, s3... 

Se eu quiser dar um "delay" ao chamar a função "criar_saudacao" eu posso retornar apenas uma referência para o local da memória que a função se encontra.

-  Quando eu não executo a função, ou seja, não ponho os **()** eu passo os argumentos normalmente e o python deve executar a função mais interna, no caso, saudar. Porém, ele é *"forçado"* a lembrar os argumentos passados. 
-  Dessa forma, quando são verificados os retornos, a função pode até ser a mesma, mas o local na memória vai ser diferente, pois é como se tivessem sido salvas varias variações da mesma função. (As variações são nos argumentos).

Em resumo, o *Closure* é quando ele *salva padronizado na memória e quando executar a função ele entrega o valor*.
