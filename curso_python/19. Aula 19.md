##### Criando arquivos com Python + Context Manager

Para abrir arquivos Python usaremos a função especial open. Porém, antes disso, vamos falar sobre caminhos. 

```Python
caminho = "aula116.txt"
```

Quando eu não informo ao programa o local em que o arquivo está ele irá abrir o mais próximo, ou seja, na pasta raiz que é a pasta em que eu estou. Porém, pode acontecer de querermos informar o caminho completo.

```Python
caminho_arquivo = "D:\Josue\Cursos\python\python\aula116.txt"
```

No Windows, há um problema com a barra invertida, pois em Python ela é usada como um caractere de escape, por esse motivo se estivermos em sistemas da Microsoft devemos ao invés de colocar uma única barra, inserir duas.

```Python
caminho_com_acento = "C:\\Users\\geenu\\OneDrive\\Desktop\\nova pasta atenção"
```

Ok, tudo certo, o nome do arquivo está definido e o caminho para encontrá-lo também, porém, o arquivo ainda não existe em nossa pasta. Sendo assim, é necessário criar e escrever. Para isso usamos a função open junto com o caracter "w". 

-  w - cria o arquivo e escreve ou apenas escreve um arquivo existente;
-  x - apenas cria um arquivo;
-  r - faz a leitura de um arquivo existente; 
-  a - escreve no final do arquivo (append mode);
-  b - arquivos binários;
-  t - (modo texto) + (leitura e escrita) (o "+" habilita escrita e leitura);
		r+ = leitura e escrita
		w+ = escrita e leitura

```Python
# Criando e abrindo um arquivo

# arquivo = open(caminho_arquivo, "r") 
# Como o arquivo ainda não existe, usando "r" ocorrerá erro de filenotfound
# Para corrigir, vamos criar um arquivo e escrver com "w"

arquivo = open(caminho_arquivo, "w")

arquivo.close()
```

Sempre que um arquivo for aberto, é necessário fechar ele

-  Podemos usar blocos try-except-finally, com o finally usado para sempre fechar o arquivo;
-  Context Manager é usado para abrir e fechar arquivos (with open);

```Python
with open(caminho_arquivo, "w") as arquivo:  
    print("Ola mundo")  
    print("Arquivo vai ser fechado")
```

A diferença usando context manager e a outra maneira que vimos, é que com o context manager o arquivo é aberto e fechado automaticamente.
##### Métodos úteis para context manager

Depois de termos um arquivo de texto prontamente para uso, podemos ler ou escrever nele, abaixo temos exemplos de ambas as situações.

```Python
with open("arquivo_teste.txt", "w") as arquivo1:  
    arquivo1.write("Linha 1\n")  
    arquivo1.write("Linha 2\n")  
  
with open("arquivo_teste.txt", "r") as arquivo1:  
    print(arquivo1.read())
```

===OBS: COMO O PRIMEIRO WITH ELE ESTÁ DEFINIDO APENAS COMO ESCRITA "W" NÃO PODEMOS COLOCAR QUALQUER CÓDIGO SEQUER DE LEITURA, ASSIM COMO NO WITH DE BAIXO NÃO PODEMOS USAR NENHUM CÓDIGO DE ESCRITA NO ARQUIVO, JÁ QUE ELE É APENAS "R"===

-  Para resolver o problema acima, usamos "w+" ou "r+"; 
-  Quando fazemos operação de leitura e escrita em um único bloco, devemos ficar atentos ao cursor. 

```Python
with open("arquivo_teste.txt", "w+") as arquivo1:  
    arquivo1.write("Linha 1\n")  
    arquivo1.write("Linha 2\n")  
    print(arquivo.read())
```

Repare o caso acima, ele consiste em leitura e escrita. Porém, como o cursor que escreve já ultrapassou as linhas um e dois, quando formos printar ele não exibirá nada. 

Para resolver isso devemos usar uma função especial que move o cursor.

```Python
with open("arquivo_teste.txt", "w+") as arquivo1:  
    arquivo1.write("Linha 1\n")  
    arquivo1.write("Linha 2\n")  
    # colocando cursor no inicio do arquivo
    arquivo.seek(0, 0)
    print(arquivo.read())
```

Alguns outros métodos importantes são:

-  writelines() - Escreve em várias linhas
```Python

	("Linha 3\n", "Linha 4\n")
)
```
-  readlines() - Lê várias linhas
```Python
for linha in arquivo1.readlines():  
    print(linha.strip())
```
-  writeline() - Escreve em uma única linha
```Python

```
-  readline() - Lê linha por linha
```Python
# readline lê linha por linha, o end="" e o strip() removem os espaços

print(arquivo1.readline(), end="")  
print(arquivo1.readline(), end="")  
print(arquivo1.readline().strip())

```

===Obs: o modo W apaga tudo que tiver no arquivo e reescreve o que o código informa===

O ponto bom de usarmos o caracter "A" como modo de uso na with open é porque ele começa a escrever na última linha do meu arquivo e não apaga o que nós tinhamos antes. "A" vem append, ou seja, ele apenas incrementa o arquivo anterior com o que escrevemos de novo. 

-  O caracter "B" abre o arquivo como modo binário.

#### O que é JSON?

De maneira simples, o JSON é um arquivo que contém uma estrutura de dados que serve para transportar e/ou também salvar dados. Os arquivos JSON tem uma estrutura parecida com os dicionários em Python.

No JSON eu posso ter cinco tipos de dados

-  Booleano;
-  Null (nulo);
-  Inteiros e Números de ponto flutuante;
-  Strings;
-  Array
-  Objetos, ex: pessoa, animal...

Quando usamos objetos em arquivos JSON normalmente ele virá em formato de par chave e valor.

Exemplo: arquivo JSON com um array de objetos do tipo Pessoa

```JSON
[
	{"nome":"Luiz", "lastName": "Miranda"},
	{"nome":"Luiz", "lastName": "Miranda"},
	{"nome":"Luiz", "lastName": "Miranda"}
]
```

Eu poderia ainda começar com um objeto e dentro do objeto ter um array

```JSON

	"name": "Luiz",
	"lastName": "Miranda",
	"age": 22,
	"addresses": [
		{"line1": "av. brasil"},
		{"line2": "av. amapa"}

```

A partir disso eu poderia ter várias informações aninhadas, a única coisa necessária é que a chave contenha aspas "" duplas, caso o valor seja uma string também deve ser usado aspas duplas.

##### O problema de parâmetros mutáveis em funções Python

```Python

    lista.append(name)  
    return lista
```

Nesse caso, como eu não passei o parâmetro de lista o problema está ai. Toda vez que a função for chamada, a lista que está no protótipo da função será o mesmo, esse é o ==problema==.

- Definir a lista fora da função

##### Evitando uso de condicionais + Guard Clause

Para um código ser considerado de fácil legibilidade é importante que ele evite ter muitos if's ou else. Dessa forma, é importante tentar deixar o código o menos identado possível.

-  Função sem "Guard Clause"

```Python
def f_noguard(x):
	if isinstance(x, int):
		# code
		# code
		# code
		return x + 1
	else:
		return None
```

O retorno do None é desnecessário uma vez que o padrão de retorno de funções Python é None.

-  Função equivalente com "Guard Clause"

```Python
def f_guard(x):
	if not isinstance(x, int):
		return None
	# code
	# code
	# code
	return x + 1
```

Uma forma de melhorar o código referente a "Lista de Tarefas" é fazer a remoção dos if's através de dicionários. 

```Python
comandos = {
	"listar": listar(tarefas),
	"desfazer": desfazer(tarefas, tarefas_refazer),
	"refazer": refazer(tarefas, tarefas_refazer),
	"clear": os.system("clear"),
	"adicionar": adicionar(tarefa, tarefas),
}
comando = comandos.get(tarefa)()
```

A variável comando procura no dicionário o valor com chave de nome "tarefa" que pode ser qualquer uma acima e após isso executa a função que é o valor. Porém, o valor do retorno já vem direto, para atrasarmos a execução da função vamos criar uma interna.



##### Positional-Only  Parameters (/) e Keyword-Only Arguments ( * )

Controlando a quantidade de argumentos posicionais e nomeados em funções Python.

-  * args (temos uma quantidade ilimitada de argumentos posicionais);
-  ** kwargs (temos uma quantidade ilimitada de argumentos nomeados);

```Python
def soma(*args):
	print(sum(args))

soma(1, 2, 3)
```

Podemos delimitar algumas coisas, por exemplo, na função acima poderiamos receber apenas *x* e *y*.

```Python
def soma(x + y):
	print(x + y)

soma(1, 2)
```

Porém, o usuário pode passar os valores nomeados ou posicionais de diferentes formas e nas ordens que ela preferir.

```Python
soma(1, 2)
soma(x=1, y=2)
```

Entretanto, caso eu queira proteger um dos meus parâmetros, como o *x* por exemplo que será agora *a* e o usuário insira ainda como *x* ocorrerá um erro. 

```Python
def soma(a, y):
	print(a + y)

soma(1, 2)
soma(x=1, y=2)
```

Vamos supor agora que eu deseje bloquear o acesso ao uso de nomes, os usuários devem usar apenas como posicionais. Para isso basta adicionar uma  / e todos os elementos antes da barra vão ser considerados posicionais.    

Exemplo

```Python
def soma(a, y, /):
	print(a+y)
soma(1, 2)
```

Isso faz com que o programador não consiga passar nenhum parâmetro nomeado que está antes da barra, ou seja, ele não vai conseguir passar argumentos nomeados para o *a* e nem para o *y*.

Podemos ainda deixar a opção de ser posicional ou não caso existam parâmetros após a barra.

```Python
def soma(a, b, /, x, y):  
    print(a + b + x + y)  
  
soma(1, 2, 3, y=3)
```

Para saber mais sobre, consultar:

- https://peps.python.org/pep-0570/

###### Keyword-Only Arguments

- Por padrão o args suga tudo e é uma tupla. 

(Breve introdução para os kwargs e Keyword-Only arguments)

```Python
def soma(a, b, *args):
	print(args)
	print(a+b)

soma(1, 2)  # saída -> () 3
soma(1, 2, "qualquer", "coisa") # saída -> ("qualquer", "coisa") 3
# empacotamento
```

Os argumentos nomeados funcionam semelhantes aos posicionais, porém usando o *\*

```Python
def soma(a, b, *, c):
	print(a + b + c)

soma(1, 2, 3)   # ocorre um erro c está como posicional
soma(1, 2, c=3) # forma correta, c como nomeado
```

-  Todos os elementos após o *\** devem ser nomeados
-  Ainda é possível mesclar as duas formas.

```Python
def soma(a, b, /, *, c, d):
	print(a + b + c + d)

soma(1, 2, c=3, d=4)
```

Dessa maneiras

1.  Todos os elementos antes da barra devem ser posicionais;
2.  Todos os elementos após o *\** devem ser nomeados;
3.  Isso não elimina o uso de kwargs, por exemplo

```Python
def soma(a, b, /, *, c, d, **kwargs):
	print(kwargs)
	print(a + b + c + d)

soma(1, 2, c=3, d=4, nome="teste", sobrenome="2")
```

-  ===Obs: kwargs por padrão é um dicionário===
