z##### While

O while pode ser escrito de duas formas diferentes em Python

-  While True;
-  While com condição explícita.

```Python
while True:
	...

while (i < 5):
	...
```

O comando *"break"*  serve como forma para quebrar o laço e fazer com que ele tenha um fim e não repita indefinidamente.

```Python
a = 0 
while True:
	a += 1
	if a == 5: break
```

O caso do break acima funciona, pois é uma forma "inline" de escrever um código.

-  Operadores de atribuição
		-  +=
		-   -=
		-   (asterisco)=
		-  /=
		- //=
		- (asterisco)(asterisco)=
		- %=

O comando *"continue"* faz com que o laço não execute o restante das instruções que vem a seguir, entretanto, ele retorna para o começo do laço. 

-  Assim como podemos fazer condicionais aninhados, também podemos fazer laços aninhados.

```Python
qtd_linhas = 5  
qtd_colunas = 5  
  
linha = 1  
  
while linha <= qtd_linhas:  
    col = 1  
    while col <= qtd_colunas:  
        print(f"{linha}, {col}")  
        col+=1  
  
    linha+=1  
  
print("Acabou")
```

* .startswith("string") é um método em python que verifica se a string começa com o argumento passado. 

O Python oferece uma ferramenta "exclusiva" em relação as outras linguagens que é o conjunto de while + else. Segue o exemplo abaixo

```Python
u = 0
while u < 10:
	...
else:
	...
```

Após o laço inteiro ser executado, **sem ser forçado com _break_** a sair o else é executado. Se tiver um **break** o else não é executado.
