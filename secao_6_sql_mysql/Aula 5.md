
#### <span style="color:rgb(4, 255, 0)">Um pouco mais sobre o DBeaver</span>

-  Por padrão o DBeaver na seção de banco de dados pode mostrar várias bases de dados, entretanto, a que está sendo desejada como trabalhada deve estar selecionada como padrão

![[Information Schema.png]]

	 No exemplo acima, se não for informado qual a base de dados vai ser usada, por padrão ele buscará na "information_schema"

-  Comentários no MySQL e DBeaver são feitos usando "--" no começo de cada linha, ou podemos usar comentários igual Python e C/C++

```SQL
-- comentário
# comentário
/* comentario */
```
