
#### <span style="color:rgb(4, 255, 0)">Signals e Slots</span>

Signals funcionam como sendo sinais enviados para um determinado widgets. Enquanto que os Slots são funções que executam uma determinada ação para aquele Signal.

-  Quando estamos trabalhando com slots é recomendado usar um decorator que está em QtCore

```Python
from PySide6.QtCore import Slot
```
